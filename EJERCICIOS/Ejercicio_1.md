## Creación de máquina virtual (ubuntu 26.04)

## Paso 1 | Abrir VirtualBox y configurar la máquina virtual

Abrimos VirtualBox y le damos a "Nueva"

![alt text](../IMAGENES/image3.png)

Ponemos un nombre a la máquina virtual y seleccionamos la ISO:

![alt text](../IMAGENES/image4.png)

Seleccionamos cuanta memoria RAM y núcleos queremos que tenga (esto ya depende de nuestro equipo local).

![alt text](../IMAGENES/image5.png)

Creamos un disco virtual con la cantidad de almacenamiento que queramos:

![alt text](../IMAGENES/image6.png)

Una vez que hayamos configurado nuestra máquina virtual, la abrimos y le damos a "Try to install ubuntu":

![alt text](../IMAGENES/image7.png)


## Paso 2 | Instalar Ubuntu

Después de unos minutos, se nos mostrará un menú.

- Elegimos el idioma del sistema:

![alt text](../IMAGENES/image8.png)

- Aqui podemos elegir el nivel de imagen, sonido, mecanografía, etc:

![alt text](../IMAGENES/image9.png)

- Seleccionamos la disposición del teclado que queramos:

![alt text](../IMAGENES/image10.png)

- Aquí podemos elegir sin conectarnos a internet o no:

![alt text](../IMAGENES/image11.png)

- Probar o instalar ubuntu, en este caso instalar:

![alt text](../IMAGENES/image12.png)

- Tipo de instalacion, en este caso seleccionamos "Instalación interactiva":

![alt text](../IMAGENES/image13.png)

- Aquí podemos seleccionar si queremos instalar más aplicaciones o menos, en mi caso voy a elegir menos para que la instalación sea más rápida:

![alt text](../IMAGENES/image14.png)

- Otros programas para instalar, en mi caso nos selecciono nada:

![alt text](../IMAGENES/image15.png)

- Podemos borrar el disco entero e instalar ubuntu en él, o configurar el disco para hacer una instalación personalizada, en este caso voy a elegir la primera opción:

![alt text](../IMAGENES/image16.png)

- Podemos elegir poner un cifrado para el sistema o no, en mi caso no:

![alt text](../IMAGENES/image17.png)

- Creamos nuestra cuenta:

![alt text](../IMAGENES/image18.png)

- Seleccionamos el horario:

![alt text](../IMAGENES/image19.png)

- Le damos a instalar:

![alt text](../IMAGENES/image20.png)

- Una vez finalizada la instalación le damos a reiniciar y ya lo tendríamos instalado:

![alt text](../IMAGENES/image21.png)
